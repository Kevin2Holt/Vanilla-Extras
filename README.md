# Vanilla Extras

A Fabric mod for Minecraft 26.3 that adds vanilla-style extras.

## Requirements

| Component | Version |
|---|---|
| Minecraft | 26.3 |
| Fabric Loader | 0.19.5+ |
| Fabric API | 0.163.0+26.3 |
| Java (JDK) | 25 |

## Building

```bash
./gradlew build
```

The mod jar lands in `build/libs/`.

## Running in development

```bash
./gradlew runClient
./gradlew runServer
```
